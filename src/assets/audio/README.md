# Audio Assets

This directory should contain ambient audio files for Velora. Add royalty-free audio files here:

## Required Audio Files

Place `.mp3` or `.wav` files in this directory with these names:

- `rain.mp3` - Rain ambience
- `wind.mp3` - Wind sound
- `ocean.mp3` - Ocean waves
- `forest.mp3` - Forest ambience
- `stream.mp3` - Flowing stream
- `birds.mp3` - Bird songs
- `piano.mp3` - Ambient piano
- `bells.mp3` - Bells/chimes
- `meditation.mp3` - Meditation bowl
- `fireplace.mp3` - Fireplace crackle
- `drone.mp3` - Ambient drone
- `cosmic.mp3` - Cosmic ambience
- `aurora.mp3` - Aurora/northern lights
- `nebula.mp3` - Deep space ambience
- `thunder.mp3` - Thunder and rain

## Free Audio Sources

Find royalty-free ambient audio from:
- **Freesound.org** - Filter by "ambient" and download Creative Commons files
- **Pixabay Audio** - https://pixabay.com/sound-effects/ (free, no attribution required)
- **Archive.org** - Internet Archive audio collections
- **Zapsplat** - Free sound effects and ambience
- **Unsplash Audio** - Free ambient audio

## Notes

- Audio will loop continuously
- Files should be in MP3 or WAV format
- Shorter files (10-30 seconds) work best for looping
- Volume is controlled by the app, so audio can be at normal levels
